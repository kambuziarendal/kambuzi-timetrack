# Restpunkter før offentlig release

- [x] AGPL-3.0-or-later er valgt og full `LICENSE` er inkludert.
- [ ] Offentlig GitHub-release opprettes fra verifisert tag.
- [ ] Fysisk Safari/iPhone og Android-test gjennomføres.
- [ ] Eksempel for automatisk kryptert off-server-backup dokumenteres for valgt driftsmiljø.

Lønn, skatt, automatisk overtidsberegning, arbeidsrettslige varsler, kontrakter og pushvarsler er bevisst utenfor gratispakken. De skal ikke presenteres som manglende feilrettinger eller som ferdige funksjoner.
